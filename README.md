# Anushka Kohli Portfolio

Personal portfolio website for internship and collaboration opportunities.

## Project Structure

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   ├── js/
│   │   └── main.js
│   └── images/
│       └── .gitkeep
└── PORTFOLIO_IMPROVEMENTS.md
```

## Files

- `index.html` contains the page content and semantic structure.
- `assets/css/styles.css` contains layout, colors, typography, responsive styles, and animations.
- `assets/js/main.js` contains menu, project filtering, and scroll reveal behavior.
- `assets/images/` is ready for profile images, project screenshots, icons, and social preview assets.

## Preview

Open `index.html` directly in a browser, or deploy the folder as a static site on GitHub Pages, Vercel, Netlify, or similar hosting.
